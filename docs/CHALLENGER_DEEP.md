# Challenger Deep — original cinematic Tagalog science Short

**Format:** 1080×1920, 30fps Remotion, animated ocean-depth scale, procedural submersible/trench graphics, synchronized Tagalog captions, and original self-generated ambient score.

**Creative note:** A science-documentary format inspired by the *genre* of hypothetical science explainers, not borrowed footage, soundtrack, animations, titles, or branding from the What If channel.

## Factual references

- NOAA: deepest known part of the ocean is Challenger Deep, approximately **10,935 m**. https://oceanservice.noaa.gov/facts/oceandepth.html
- NOAA: very little sunlight remains below 200 m; **no sunlight** in the aphotic zone below 1,000 m. https://oceanservice.noaa.gov/facts/light_travel.html
- NOAA: pressure increases by about **one atmosphere every 10.06 m**. https://oceanservice.noaa.gov/facts/pressure.html

## Preview: generate a real Filipino voice and render an MP4

The workflow `.github/workflows/challenger-deep.yml` creates genuine Filipino speech using an **Edge TTS voice** (`fil-PH-AngeloNeural`), falling back to Filipino gTTS if unavailable. The preview's speech **is not generated by VoxCPM2**.

CI builds the script and 1080×1920 MP4 using Remotion with AAC audio, verifies dimensions and streams with ffprobe, and uploads `challenger-deep-tagalog.mp4`, a poster PNG, captions props and the narration provenance JSON.

## Replace the preview speech with standalone VoxCPM2 WAV

Generate your Tagalog `narration.wav` in the *separate official repository* https://github.com/OpenBMB/VoxCPM on a GPU runtime (such as Google Colab). Import it to the editor as `input/challenger.wav`. Do not commit model weights, recordings or tokens.

```bash
npm ci
python3 scripts/make-original-challenger.py --external-wav input/challenger.wav
frames="$(python3 -c 'import json; print(json.load(open("out/challenger-props.json"))["totalFrames"]-1)')"
npx remotion render ChallengerDeep out/challenger-voxcpm2-candidate.mp4 \
  --props=out/challenger-props.json --frames="0-$frames" \
  --codec=h264 --pixel-format=yuv420p
```

This imports the WAV into the video via FFmpeg without installing the model in Codespaces. Caption times for externally supplied audio are approximated proportionally and should be reviewed. An external WAV is **not proof that VoxCPM2 produced it**; only mark production voice quality verified after actual upstream GPU generation and listening QA. Standard GitHub-hosted Actions runners do not provide the NVIDIA GPU recommended for VoxCPM2.

**Render status:** Look at the CI result for proof of the produced artifact; a committed composition alone is not a verified MP4.
