# 12 Cinematic FX — actual motion, not slides

These effects extend (do not replace) the **21 original FX** to a total of
**33 reusable effects** in the `FxPreview` and `ExampleEdit` editor APIs.
Existing IDs, cut lists, timeline formats, character registry, voices and
compositions are unchanged. All twelve effects animate the underlying
**frame-accurate source footage** at 1080×1920 and 30fps. Some require the
real per-frame foreground matte from `make-fg.py`. They do **not** insert
a project title, watermark, numbered label, grid or footer.

## Effect registry

| FX ID | Motion action | Source |
|---|---|---|
| `rgb-split` | Subject RGB separation, animated interference | Local Video + tracked matte |
| `speed-trails` | Eight glowing motion trails chase the foreground | Local video + matte |
| `film-light-leak` | Moving warm anamorphic flare and bloom | Local video |
| `glass-shatter` | 24 actual animated cutout fragments with outward force and gravity | Local video + matte |
| `liquid-displacement` | **SVG procedural displacement filter** warps actual video | Local video |
| `pixel-dissolve` | Pixel field fragments cover/dissolve the tracked character | Local video + matte |
| `whip-pan-blur` | Two moving shots exchange positions with directional blur | Local video |
| `svg-path-morph` | Real `@remotion/paths.interpolatePath` + `evolvePath` line drawing | Local video + matte |
| `comic-halftone` | Contrast, locally generated print dots and subject pop | Local video + matte |
| `shader-portal` | Circular viewport to a second real source offset with procedural turbulence displacement | Local video |
| `film-burn-reveal` | Irregular-feel glowing reveal with hot burn rim | Local video |
| `audio-reactive-particles` | 90 animated particles follow the **actual measured 30fps RMS** of an original generated 4-second stereo PCM sample | Local video + matte + original audio |

The effects are not an exact pixel copy of specific After Effects plugins.
They are original implementations. There is **no stock or third-party video**,
GPU, HeyGen cloud, paid API, third-party music or unsanctioned asset.
Approved UrFavXBF and PIX poses remain untouched.

## Critical version and licensing limits

- The repo remains pinned to Remotion **4.0.522**. Official newer
  `shatter()` (v4.0.539) and `filmBurn()` (v4.0.540) **cannot** be imported
  from this version. The corresponding entries above are independently
  authored CSS/DOM-composition approximations, **not those official APIs**.
  This avoids a risky mass framework upgrade or GPU dependency.
- `shader-portal` is an **SVG displacement-filter equivalent**, not a GLSL
  shader copied from the GL Transitions project. That project requires
  a source-level license review for each shader; no third-party shader
  was copied. The built-in version works in regular Chromium CPU mode.
- The official package `@remotion/paths@4.0.522` is MIT-licensed
  and kept in exact version lockstep with the existing Remotion packages.
- `audio-reactive-particles` uses actual RMS measured over original
  synthesized WAV samples generated by `generate_advanced_fx_audio.py`.
  The committed JSON is compared with regenerated RMS in CI. It does not
  infer amplitude from the clock or claim phoneme lip-sync.
- A matte is not automatic image segmentation: it must be synchronized
  and manually inspected for the chosen source. Don't claim support for
  arbitrary videos without providing actual masks.

## Use in editor

```bash
npm ci
python3 -m pip install -r requirements.txt
python3 scripts/stage_pixel_default_pack.py --verify-workspace
npm run advanced-fx:sample
npm run typecheck

# One effect, with the supplied local sample/mattes:
npx remotion still FxPreview out/rgb-split.png \
  --props='{"id":"rgb-split","from":10}' --frame=25

# All twelve; full-frame original source with no permanent branding:
npm run advanced-fx:showcase
```

For a real edit, set a segment's `kind: "fx"` and choose any new FX ID.
`src/compositionMetadata.ts` validates all 33 IDs; provide the existing
`source.video`, `source.matte`, `source.sticker`, `source.frames` and
`source.face` fields with physically present files and verified bounds.
The legacy `FxShowcase` still displays only the original 21, while
`AdvancedFxShowcase` renders only the new 12, deliberately without labels.

## Deliverable and QA

The branch-only GitHub Actions workflow installs the exact package lock,
generates all source frames plus the real original audio, tests the 12
effects, renders multiple frames and a **true H.264 preview** with FFprobe
and decode check. This tests the integration, not a fully mastered episode.
Before client delivery, inspect individual effects on their chosen media,
visual quality, original narration and licensed sound design.
