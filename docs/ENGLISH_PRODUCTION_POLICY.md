# Archived English-only production policy

The prior English-only default was superseded on October 28, 2026 by
[the multilingual production policy](MULTILINGUAL_PRODUCTION_POLICY.md).

**New original videos default to Tagalog/Taglish (`tl`)** in scripts,
character dialogue, narration, motion-graphic labels, captions and YouTube
metadata. **English (`en`) remains an explicit option** with the historical
Chatterbox V3 character voices.

Earlier English episodes, voice samples, scripts and workflows remain
preserved as historical content. This document is retained for compatible
links, not as the current default policy.
