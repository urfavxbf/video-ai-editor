# Original Motion Director

A skills-only ChatGPT/Codex plugin for original motion graphics using [video-ai-editor](https://github.com/urfavxbf/video-ai-editor).

## Included

- Original Motion Director: creative choices, storyboards, voice/character/caption synchronization and audiovisual QA.
- Host Workspace Operator: portable file and repository handling.
- Sandbox Python Executor: evidence-based deterministic verification when host execution is available.

No premade video templates, MCP service, hooks, telemetry, render server, voice models, or character binaries are bundled. Tool access and external services remain controlled by the host and user. Asset rights must be checked before production.

## Use

Import the ZIP on a compatible plugin upload/testing surface. If that surface is unavailable, the package is still usable by a compatible local plugin host; public-directory publication is separate. Start with: “Plan an original UrFavXBF and PIX video and give me creative choices.”

The assistant asks at creative checkpoints and respects prior approvals or explicit delegation. Final video rendering requires actual repository access, dependencies, assets, and compute. A moving talk sprite is not verified phoneme lip sync.
